## Pubblicare con GitHub Pages

1. Crea un nuovo repository su GitHub e carica tutti i file di questa cartella (index.html deve stare nella radice).
2. Vai in Settings > Pages.
3. In "Build and deployment" scegli Source: "Deploy from a branch", branch "main", cartella "/ (root)", e salva.
4. Dopo uno o due minuti l'invito è online all'indirizzo https://NOME-UTENTE.github.io/NOME-REPOSITORY/

Le conferme arrivano nel Google Form collegato al pulsante "Conferma la tua presenza".
